# Alice

**Herkes için Linux wiki** 🐇

Linux ve linuxdaki her şeyi sıfırdan öğrenmek isteyenler için Türkçe, açık ve ücretsiz bir wiki.

[Wikiyi buradan ziyaret edin](https://bilikon-project.github.io/alice/)

---

## Yeni konu ekle

1. `docs/yeni-konu.md` oluştur
2. `index.html` içindeki `TOPIC_FILES`'a ekle
3. Bitti.

Detaylı rehber: [`docs/templates.md`](docs/templates.txt)

## Katkı

Fork'la, konu ekle, PR gönder. Kurallar için `docs/templates.md`.
